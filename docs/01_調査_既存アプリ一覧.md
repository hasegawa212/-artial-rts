# STEP 1 調査：既存アプリ一覧（2026-10-28）

## 調査方法と限界

- アクセスできた GitHub リポジトリ（`list_repos` で 10 件）のうち、業務に関係する 5 件を読み取り専用で clone し、README・デプロイ設定（`netlify.toml` / `render.yaml` / GitHub Actions）・CLAUDE.md を読んだ。**コード・DB・URL・設定は一切変更していない。**
- **稼働確認はできていない**：このクラウド環境からの外向き HTTPS は遮断されており（`curl` は全 URL で接続不可 = HTTP 000）、どの URL も実際に開けるかを確かめられなかった。そのためポータルでは「稼働確認済み」は 0 件、デプロイ設定・README に URL が書いてあるものを **「稼働未確認」** としている。
- **管理者（担当者）** を書いた資料は見つからなかったため、全件「未確認」。
- ブリーフに名前のある **`ma-customer-management` / `fp` / `Chat-Bridge` は、このセッションのアカウントからは一覧に出てこず、アクセスできなかった**（別オーナーか、GitHub App 未インストールの可能性）。中身はすべて「未確認」。
