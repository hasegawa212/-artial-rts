# STEP 2 UI/UX 設計 — LUXURY AI ENTERPRISE

## 方針
装飾より **操作速度と見やすさ**。黒・ディープネイビー・シャンパンゴールドの 3 色だけで高級感を出し、ゴールドは「選択中・主要ボタン・アイコン」にだけ使う。

| トークン | ライト | ダーク | 用途 |
|---|---|---|---|
| `--bg` | #f6f4ef（アイボリー） | #07080b（ブラック） | 背景 |
| `--surface` | #ffffff | #0d1424（ネイビー） | カード |
| `--navy` | #0f1f3d | #0b1a33 | ヒーロー・アバター |
| `--gold` | #8f7034 | #d6bb80 | 文字のゴールド（ライトは 4.5:1 以上になる濃さ） |
| `--gold-soft` | #c9a961 | #c9a961 | 主要ボタン・線 |

- テーマ：ライト / ダーク / 端末に合わせる（Cookie `mao_theme`、サーバーで初期描画するのでちらつかない）。
- 文字：日本語ゴシック（Hiragino / Noto Sans JP / Yu Gothic UI）。ロゴのみ欧文セリフ＋字間 0.32em。外部フォントは読まない（CSP）。
- アイコン：lucide（線幅 1.6 で統一）。
- 動き：カードの浮き上がり・フェードのみ、`prefers-reduced-motion` で無効。

## 画面
| 画面 | パス | 内容 |
|---|---|---|
| ログイン | `/login` | 左にブランド、右に「社内アカウントでログイン」（OIDC）。開発モード時だけ 3 ロールの仮ログイン |
| ホーム | `/` | あいさつ・検索・お気に入り・最近使用・カテゴリー・すぐに開けるアプリ |
| すべてのアプリ | `/apps` | カテゴリーのチップ＋絞り込み検索、カテゴリー別の見出し |
| アプリ詳細 | `/apps/[id]` | 開く／開けない理由、URL・出典・認証方式・管理者・リポジトリ |
| お気に入り | `/favorites` | |
| 社員プロフィール | `/profile` | 氏名・メール・ロール・できること・テーマ・ログアウト |
| 管理者 | `/admin` | アプリ台帳（URL 確認状況の変更）・利用者とロール・監査ログ |

- PC：左サイドバー（248px）＋上部検索バー。スマホ（<768px）：下部ナビ（ホーム / アプリ / 検索 / お気に入り / マイページ、タップ領域 56px）。
- 全アプリ検索：⌘K / Ctrl+K / 「/」、スマホは下部中央の検索ボタン。ひらがな・カタカナ・全角半角・長音を区別しない。
- 開けないアプリは「開く」を出さず理由を表示（URL未確認のため接続しません / LINE・チャットから使うアプリです / 凍結中 など）。
